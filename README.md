# Dashboad_xbox
🎮 Dashboard de Vendas Xbox com Excel
📌 Sobre o Projeto

Este projeto foi desenvolvido durante o curso da DIO com o objetivo de criar um dashboard interativo no Excel para análise de assinaturas do ecossistema Xbox.

O dashboard foi construído a partir de uma base de dados contendo informações de clientes assinantes dos planos Xbox, permitindo acompanhar métricas de vendas, tipos de assinatura e serviços adicionais contratados.

🎯 Objetivos
Organizar e tratar dados de assinaturas Xbox.
Criar análises utilizando Tabelas Dinâmicas.
Desenvolver indicadores de desempenho através de Dashboard.
Aplicar fórmulas do Excel para automação de cálculos.
Utilizar filtros para análise dinâmica das informações.
📊 Base de Dados

A base contém informações como:

Subscriber ID
Nome do assinante
Plano contratado (Core, Standard e Ultimate)
Data de início da assinatura
Renovação automática (Auto Renewal)
Tipo da assinatura (Monthly, Quarterly e Annual)
EA Play Season Pass
Minecraft Season Pass
Valor de cupons aplicados
Valor total da venda

📈 Indicadores Analisados

O dashboard permite visualizar:

Total de vendas das assinaturas

Participação dos planos Xbox nas vendas
